# 丝袜与百褶裙 · three.js 物理模拟

three.js 演示：可捏起回弹的丝袜 + 带刀褶的格纹百褶裙布料模拟。人体来自 MakeHuman 基础网格（CC0），贴图全部程序化生成。

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 输出到 dist/
```

## 操作
- 拖拽丝袜：捏起拉伸，松手回弹（拉得过远会脱手）
- 拖拽裙子：掀动 / 拉扯布料
- 拖拽背景：旋转视角；滚轮缩放；右键平移
- 右侧面板：丝袜颜色 / 厚度(丹尼) / 光泽 / 丝光条纹 / 加固袜尖脚跟 / 背缝线 / 松紧 / 款式，裙子面料 / 裙长 / 褶数 / 重量 / 空气阻力，风，动作（摇摆、转圈、跳跃、屈膝）

## 渲染风格
面板顶部的“渲染风格”可在 **动画**（赛璐珞色阶、硬边高光、深度描边，见 `src/toon.js`）与 **写实** 之间切换，物理模拟两者共用。

## 实现
- `assets/makehuman/base.obj` MakeHuman 基础人体网格（CC0）
- `tools/fit-body.mjs` 把人体网格重采样成腿 / 骨盆的规则网格，生成 `src/bodydata.js`（`node tools/fit-body.mjs`）
- `src/body.js` 腿与躯干，CPU 蒙皮（髋、膝、踝、跖趾），裙子用的碰撞体
- `src/stockings.js` 丝袜材质（随视角与拉伸变化的纤维遮盖率、纤维方向的各向异性高光、线圈微法线、关节细褶、加固区与背缝、袜口）与只受拉的弹性薄膜 PBD 模拟
- `src/skirt.js` 裙子 PBD 布料（风、空气阻力、身体碰撞），褶子随周向拉伸展平的几何重建
- `src/textures.js` 程序化格纹面料（经纬纱按 2/2 斜纹交织，附高度图）
- `src/materials.js` 皮肤（毛孔、肤色不匀、次表面散射）与罗纹针织上衣的程序化材质
